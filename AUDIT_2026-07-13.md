## This session's three bug-fixes - independently reviewed, all CORRECT

1. **Preference-encoder off-by-one** (`training.py`). All four encoders (DPO/SimPO/KTO/
   ORPO) now route through `Trainer._encoded_prompt_len`, which drops the trailing EOS so
   the first completion token is no longer masked out of the gradient. Verified all 4 sites
   use the helper; the 4 `prompt_len = len(prompt_ids)` sites in `rl_training.py` are a
   different, non-buggy structure (the ids are the literal generation tensor). Regression
   test: `tests/test_preference_encoding.py`.
2. **LoRA offload device mismatch** (`lora_utils.py`). `cpu=` now tracks GPU presence, not
   `offload_optimizer`; batches follow `accelerator.device`. Regression test:
   `tests/test_lora_offload.py`.
3. **Resume/out clobber** (`pretrain_enigma.py` + `extend_length.ps1`). Bare `--resume`
   writes back to the checkpoint's own dir; `extend_length.ps1` resumes an existing 2048
   run instead of warm-starting from step 0. (Closes ULTRAREVIEW major #4.)
